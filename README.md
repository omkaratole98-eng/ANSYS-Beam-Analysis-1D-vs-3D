# Beam Stress & Deformation Analysis
## Analytical Validation using 1D and 3D FEA in ANSYS Mechanical

---

## 📌 Overview

This project presents a comparative structural analysis of a beam using
analytical calculations and Finite Element Analysis (FEA) in ANSYS Mechanical.

The beam was analyzed using three approaches:

1. **Analytical calculation** using classical beam theory
2. **1D beam-element analysis** in ANSYS Mechanical
3. **3D solid-element analysis** in ANSYS Mechanical

The objective was to validate the FEA results against the analytical solution
and investigate the differences between 1D and 3D finite element modelling.

---

## 🎯 Objectives

- Calculate the beam's stress and deformation analytically.
- Develop a 1D beam-element model in ANSYS Mechanical.
- Develop a 3D solid-element model in ANSYS Mechanical.
- Apply appropriate loading and boundary conditions.
- Compare stress and deformation obtained from different approaches.
- Calculate the percentage error between FEA and analytical results.
- Understand the effect of element type and modelling approach on the results.
