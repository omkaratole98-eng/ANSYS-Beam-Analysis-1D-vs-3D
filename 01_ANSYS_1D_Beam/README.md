# 1D Beam Element Analysis

This section contains the finite element analysis of the beam using 1D beam elements in ANSYS Mechanical.

## Analysis

The beam was modelled using 1D beam elements and analyzed under the specified loading and boundary conditions.

The following results were obtained:

- Total deformation
- Equivalent (von-Mises) stress

The 1D FEA results were later compared with the analytical solution and the 3D solid-element model.
